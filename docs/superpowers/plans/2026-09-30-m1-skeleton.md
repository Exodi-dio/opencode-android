# M1 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land M1 skeleton that compiles, greens CI, and produces a downloadable debug APK, with all modules, devcontainer, workflows, and mock LLM in place.

**Architecture:** Full multi-module from day one (A) with pure-Kotlin discipline (C): `:core:agent,tools,providers,config` have zero `android.*` imports; only `:core:session` (Room) and `:core:permission` (Keystore/FGS bridge) touch Android. UI is a minimal Material 3 shell mirroring official opencode information architecture (sessions list, chat empty state, model/agent picker stub).

**Tech Stack:** Kotlin 2.0.21, AGP 8.5.2, Gradle 8.10.2, compileSdk 35, targetSdk 35, minSdk 26, Compose BOM 2024.09.00, Hilt 2.51.1 (ksp), Room 2.6.1, Ktor client 2.3.12 (ContentNegotiation + SSE), kotlinx.serialization 1.7.3, coroutines 1.9.0, JGit 6.10.0 (dependency only, unused until M4/M6), JUnit4 + Robolectric 4.13 + Paparazzi 1.3.2 + Roborazzi 1.27.0, ktlint 12.1.2, detekt 1.23.7. If a pinned version fails to install in Codespaces, bump to nearest stable and record the change in `docs/parity.md`. JDK 21, NDK r27 (27.2.12479018), cmdline-tools 11076708.

**Spec:** `docs/superpowers/specs/2026-09-30-opencode-android-design.md`

## Global Constraints

- Cloud-only, zero hardware: all compile/test/debug/release in GitHub Codespaces + GitHub Actions. Never add a step needing a local computer, physical phone, or local emulator. Never write "test on a device".
- Native Kotlin reimplementation, MIT + attribution kept, README non-affiliation note required. Do not embed Bun/Node.
- minSdk 26, targetSdk 35 (bump only with parity entry), no Google Play Services / Firebase, F-Droid friendly.
- Pure-Kotlin discipline: `agent/tools/providers/config` contain no `android.*` imports (enforced by test).
- NDK ABIs `arm64-v8a` + `x86_64`, linker flag `-Wl,-z,max-page-size=16384`, `useLegacyPackaging = true` for `lib*.so`.
- Foreground-service type correct for API 34+ when FGS lands (M3/M5); M1 only declares permission, no service.
- Mock LLM only: no API keys in tests, deterministic fixtures.
- Small commits, PR per milestone, every upstream-behavior decision in `docs/parity.md`.
- Official opencode UX parity: same screens/element semantics, natively restyled, mobile-perfect gates (no clipping/overlap/scroll loss), TalkBack labels, weak-hardware budgets.

## Review Focus

- Workspace path `../secrets/key` passed to a file tool resolves outside root and must be denied with an audit event (Task 6 owns the test).
- Permission pattern `bash:*` with rule `deny` must beat a later `allow` (upstream precedence: deny wins); a bypass attempt returning allowed is a security bug (Task 6).
- 10 MB tool output must truncate with `[truncated]` + byte count, never OOM the JVM test (Task 6).
- Rotation during streaming chat must not lose scroll position or crash collectors (Task 7).
- Low-RAM emulator (2 GB, API 30) cold start must stay under budget and must not ANR; failure goes to `docs/limitations.md`, never to a hardware ask (Task 5 + Task 7).
