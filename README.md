# opencode-android

Native Kotlin port of [opencode](https://github.com/anomalyco/opencode) for Android:
same product behavior and information architecture, reimplemented in Kotlin with
Jetpack Compose (Material 3), with no Bun/Node runtime embedded.

> Disclaimer: this is an independent community port. It is not affiliated with,
> endorsed by, or sponsored by the upstream opencode project or its maintainers.
> Upstream source remains under its MIT license; see `LICENSE` and `UPSTREAM.md`
> for the pinned upstream commit this port tracks.

> Cloud-only: every build, test, and CI step runs in GitHub Codespaces and GitHub
> Actions. No step requires a local computer, a physical phone, or a local emulator.
